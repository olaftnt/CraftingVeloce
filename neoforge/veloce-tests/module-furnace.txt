# Module: furnace  (smelting, blasting, smoking)
#
# Cases covered:
#   1. full accumulator                  -> the terminal must deliver the item
#   2. accumulator drained to ZERO       -> must refuse, and say it is power
#   3. accumulator partly filled         -> must still refuse (too little for a smelt)
#   4. full accumulator again            -> must deliver again
#
# The order matters. Case 1 proves the module works at all; cases 2 and 3 prove
# the machine actually READS its charge instead of smelting for free - a bug that
# a "does it craft" test alone would never show; case 4 proves refusing did not
# leave the machine stuck.
#
# Watch it:  ./gradlew :neoforge:runTestClient -PveloceTest=module-furnace -PveloceKeepOpen

# --- case 1: powered ---
/cv testmodule furnace
expect: building and waiting

wait: 120

/cv testmodule result
expect: PASS

# --- case 2: no power at all ---
/cv testmodule furnace
expect: building and waiting

/cv testmodule fe 0
expect: FE set to

wait: 120

/cv testmodule result
expect: FAIL

# --- case 3: some power, but not enough for a smelt ---
/cv testmodule furnace
expect: building and waiting

/cv testmodule fe 1
expect: FE set to

wait: 120

/cv testmodule result
expect: FAIL

# --- case 4: powered again ---
/cv testmodule furnace
expect: building and waiting

/cv testmodule fe 1000000
expect: FE set to

wait: 120

/cv testmodule result
expect: PASS
