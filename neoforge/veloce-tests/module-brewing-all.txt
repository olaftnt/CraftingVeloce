# Why this file exists next to the random sweep: the sweep proves the module works
# for SOME of its items. Only naming all of them proves it works for ALL, and this is
# the file that answers "can every potion be made". Regenerate the list with:
#
#     /cv testmodule list brewing

# twelve different ingredients, so "brewing_mundane" alone could not identify a
# recipe. A failing case names the route, which is what makes it reproducible.
#

# module-brewing-sweep.txt (25 draws) or module-brewing-named.txt (pinned recipes).
#
# Watch it:  ./gradlew :neoforge:runTestClient -PveloceTest=module-brewing-all -PveloceKeepOpen
