# Module: alchemistry  -  one case per MACHINE BLOCK (7 found).
#
# A compat module is a FAMILY: Mekanism alone registers twenty-three machines, each
# its own block. Testing the family through one block would draw a recipe belonging to
# a different machine and report a failure that says nothing about either, so every
# block gets its own case and /cv testmodule only accepts a recipe the placed block can
# actually perform.
#
# These machines need FORGE ENERGY. Power is a separate axis from "can this module
# craft at all", and the three cases differ in what they answer:
#
#   1. accumulator at ZERO        -> must REFUSE, naming power as the reason
#   2. accumulator partly filled   -> must STILL REFUSE (too little for one operation)
#   3. accumulator full            -> must DELIVER the item
#
# SKIP is an accepted answer on every case, and it is not indecision: SKIP means this
# machine has no recipe in the current pack, so there was nothing to test. That is a
# fact about the pack, not about the machine - and reporting it as FAIL would bury the
# real failures under a hundred lines that say nothing.
#
# A freshly placed machine has NO charge, so case 1 is also the "did we forget to
# charge it" check. Testing only case 3 would pass on a machine that crafts for free -
# cases 1 and 2 are what prove the charge is really read, and case 3 after them proves
# a refusal does not leave the machine stuck.
#
# Watch it:  ./gradlew :neoforge:runTestClient -PveloceTest=module-alchemistry -PveloceKeepOpen
