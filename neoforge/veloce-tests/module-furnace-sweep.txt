# Module: furnace  -  SWEEP over 25 independently drawn recipes.
#
# Why a sweep and not one case: /cv testmodule draws a recipe at RANDOM from
# everything the module offers. One run therefore proves the module works for
# ONE item; 25 runs prove it works for 25 of them. Re-running the same script
# draws a different set, so items are never retested in the same order.
#
# A failing draw prints the recipe id, which can be replayed exactly:
#     /cv testmodule furnace electric_furnace <recipe-id>
#
# Watch it:  ./gradlew :neoforge:runTestClient -PveloceTest=module-furnace-sweep -PveloceKeepOpen
