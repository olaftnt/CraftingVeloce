# The brewing stand's OWN brewing path - not the terminal.
#
# STATUS: RED, on purpose. This script reproduces an OPEN bug, so a failing run is
# the expected result until it is fixed - do not "fix" it by relaxing the assertions.
# What it currently shows: a freshly placed stand never brews at all. After the full
# 460 ticks the bottle still holds the potion that went in and the stand's energy is
# untouched, i.e. its serverTick either never runs for a block placed by setBlock()
# or the brew is aborted before it starts. Stands LOADED FROM THE SAVE do tick, which
# is what made this hard to see: every stack-trace probe fired on a leftover stand
# from an earlier run rather than on the one under test.
#
# Why a separate file: /cv testmodule drives the terminal, and auto-crafting goes
# through VeloceAutoCrafter, which inserts recipe.primaryResult() itself and never
# calls the stand's doBrew(). A stand that got the vanilla mix() argument order wrong
# therefore passed every terminal test ever run against it while brewing BY HAND was
# broken - which is exactly the "I can't make a mundane potion" report.
#
# /cv brewcheck puts a real potion and a real ingredient into a real stand, lets the
# machine's own tick run the full 400-tick brew, and compares the bottle slot against
# the result the game computes independently (level.potionBrewing().mix(...)).
#
# Watch it:  ./gradlew :neoforge:runTestClient -PveloceTest=stand-brewing -PveloceKeepOpen

# --- water + redstone -> Mundane (the potion from the bug report) ---
/cv brewcheck "minecraft:water" "minecraft:redstone"
expect: brewcheck

wait: 480

/cv brewcheck result
expect: PASS
expectnot: FAIL

# --- a chain step: awkward + golden carrot -> Night Vision ---
/cv brewcheck "minecraft:awkward" "minecraft:golden_carrot"
expect: brewcheck

wait: 480

/cv brewcheck result
expect: PASS
expectnot: FAIL

# --- a transformed potion: night vision + fermented spider eye -> Invisibility ---
/cv brewcheck "minecraft:night_vision" "minecraft:fermented_spider_eye"
expect: brewcheck

wait: 480

/cv brewcheck result
expect: PASS
expectnot: FAIL
